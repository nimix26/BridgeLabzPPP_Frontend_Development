Task 20: Head elements explanation

<title> — Specifies the title of the document shown in the browser tab.
<meta charset="UTF-8"> — Declares the character encoding for the document.
<meta name="description"> and <meta name="author"> — Provide metadata about the page and author.
<base href="..."> — Sets the base URL for relative links on the page.
<link rel="icon" href="..."/> — Links external resources such as a favicon.
<style> — Embeds CSS rules (kept empty per assignment instructions).
<script> — Embeds JavaScript (kept empty per assignment instructions).

All these tags were included inside the <head> at the top of this document.
