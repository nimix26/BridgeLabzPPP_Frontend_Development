Exploring Typography

This article demonstrates various CSS typography properties. We are using 'Merriweather' for headings and 'Lato' for body text. Notice the ::first-letter pseudo-element, which is large and orange, and the ::first-line, which is bold. Good typography is crucial for readability and user experience.

You can control many aspects of text. For instance, this paragraph has a line-height of 1.7, which adds comfortable spacing between lines. We can also change letter-spacing, though it's often best left alone for body text. This text is set to text-align: justify;.

Inline Styling

CSS allows us to style inline elements. For example, we can make important text (strong) stand out with a custom color. We can also draw attention to highlighted text (mark) with a different background. Even emphasized text (em) can be given a unique style, not just italics.

We can also style text with different weights. This text is font-weight: 400 (regular). This text is 300 (light). And this text is 700 (bold). Using a variety of weights adds visual hierarchy.
